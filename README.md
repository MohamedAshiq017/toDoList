#  **Todo List App** – Task Management with Node.js & PostgreSQL  

A simple **To-Do List application** built using **Node.js, Express, PostgreSQL, and EJS** for managing tasks with **Create, Read, Update, and Delete (CRUD) operations**.  

 **Easily add, edit, or remove tasks and track your progress!**  

---  

##  **Features**  

 Add new tasks to the list  
 Edit existing tasks with updated titles  
 Delete tasks when completed  
 Store tasks in a **PostgreSQL database** for persistence  
 User-friendly **EJS templating engine** for a dynamic UI  
 API routes for **seamless data management**  

---  

##  **How to Use**  

1️ Open the app in your browser.  
2️ Enter a **task** in the input box and click **Add**.  
3️ Tasks appear in the list and can be **edited or deleted**.  
4️ All tasks are stored in **PostgreSQL**, ensuring data persistence.
